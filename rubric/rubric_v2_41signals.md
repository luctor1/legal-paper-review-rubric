# 中文法学论文审稿评分表 · 41 信号版

> A rubric-based review standard for Chinese legal academic papers (41 signals, 0–4 scale)

一套用于评估中文法学论文能否达到核心期刊（C 刊）发表水准的评分表。

面向的典型场景：编辑初审、审稿人评分、以及为自动评审系统提供可执行的判定标准。

- **版本**：v2.1
- **更新日期**：2026-11-01
- **条目**：41 条计分信号 + 5 条形式合规 + 5 条红线
- **刻度**：0–4 五档

---

## 一、设计原则

**1. 评的是"能不能发表"，不是"写得好不好"。**
学术写作的很多特点（长句、术语密集、注释繁多）本身不加分也不减分。真正要判的是：这篇文章有没有回答一个值得回答的问题，并且论证成立。

**2. 三层结构，权重递减。**

| 层级 | 评什么 | 信号数 | 分值占比 |
|---|---|---|---|
| H1 思维结构力 | 问题是否成立、论证是否推进、结论是否落地 | S01–S11 | 约 1/3 |
| H2 文字材料驾驭力 | 表达、概念、方法、文献 | S12–S27 | 约 1/3 |
| H3 问题价值与贡献力 | 选题含量、创新、应用价值 | S28–S41 | 约 1/3 |

顺序即优先级：**结构不行，材料再好也救不回来**。

**3. 每条信号都必须同时给出「抽象原则 + 具体信号」。**
只有原则会变成主观感觉，只有信号会变成机械打勾。两者配对，评分才有可复现性。

**4. 每条信号绑定固定的「证据位置」。**
同一个信号永远去同一处找证据（摘要、结语、参考文献列表……）。这是减少评分漂移最有效的一条。

**5. 形式合规与红线不计分，只做通过/否决。**
它们不适合用程度来衡量——字数不够就是不够，造假就是造假。

---

## 二、刻度制：0–4 五档

全面弃用 0/1 二分。理由：二分会把"有点问题"和"完全没做"压成同一档；百分制又太细，人和模型都判不出 73 与 75 的区别。

| 分值 | 档位 | 通用锚点 |
|---|---|---|
| 0 | 缺失 | 完全未涉及 / 完全做不到 |
| 1 | 不足 | 有尝试但严重不达标 |
| 2 | 合格 | 达到发表底线，无明显亮点 |
| 3 | 良好 | 明显超过底线，有可点名的长处 |
| 4 | 优秀 | 可作同类标杆 |

每条信号在各档写有专属锚点描述（见后文，主要给出 0 / 2 / 4 三档，1 与 3 为过渡档）。

**计分方法**

```
维度分 = Σ(信号分 × 权重) / Σ(权重 × 4)     → 0~1
百分制 = 维度分 × 100
```

权重：核心信号 ×1.0，辅助/收窄信号 ×0.5。

## 三、形式合规层（过 / 不过，不计分）

| 编号 | 检查项 | 判定说明 |
|---|---|---|
| F1 | 正文字数 10000–30000 字（含参考文献、不含附录） | 不过线但聚焦具体问题的短篇 → 放行并标记"短篇档"；长篇空泛反而在 H1 失分。注意防"短篇凑合集栏目" |
| F2 | 中文摘要 150–300 字 + 关键词 3–5 个 | 摘要不得"本文从 X 角度讨论 Y 问题"套话开头，须包含核心结论。案例评述型无摘要关键词 → 走特例（见结构标签说明） |
| F3 | 参考文献 ≥15 篇、覆盖中英文、近 5 年 ≥50%、GB/T 7714 体例 | 体例：作者-题名-期刊-年份-期号-页码；不混用 APA |
| F4 | 中英文标题严格对应（英文摘要非强制但加分） | — |
| F5 | 脚注序号连续、文末文献与脚注对应 | — |

## 四、红线层（一票否决，不计分）

| 编号 | 红线 | 判定依据（抽象原则 + 具体信号） |
|---|---|---|
| X1 | AI 生成痕迹 | 原则：AI 稿的本质是"无作者的平均化表达"。信号：三要素同时满足——内容空泛 + 缺乏个人观点 + 高频套话密度超标（"综上所述/值得注意的是/不可否认"等每千字 ≥2 次）。法学严谨句式属正常风格，单独出现不算 |
| X2 | 空泛无支撑 | 原则：应然口号不能替代论证。信号：连续 3 段以上"应当构建/应当完善"类段落，且无立法、判例或数据支撑 |
| X3 | 假引 | 原则：引用必须可验证。信号：CNKI 检索不到 / 作者年份期刊号不匹配 / 杜撰书名。必须提供具体核查证据，"没听过"不算命中 |
| X4 | 抄袭 | 原则：文字重合与思想挪用都算。信号：≥200 字连续重合率 >80%；查重率 ≥20%；同时核查 AI 生成内容比例 |
| X5 | 隐性不标 | 原则：转引不标 = 隐性抄袭。信号：非原创观点无脚注 / 转引未注"转引自 XXX" |

## 五、H1 思维结构力（S01–S11）

统摄三个维度：D1 问题链条、D2 论证结构、D3 结论质量。

设计要点：问题从提出到解答的完整链条——标题与文首是否给出问题 → 问题体量与篇幅是否匹配 → 小标题是否充分分拆覆盖 → 每个子问题是否在文末得到解答（消除合理怀疑，确保读者确信分论点成立）。

### H1-D1 问题链条

| 编号 | 信号 | 判定依据 | 刻度锚点（0/2/4） | 证据位置 | 权重 |
|---|---|---|---|---|---|
| S01 | 问题提出质量 | **原则**：三问递进——是不是问题（是否存在真分歧/真困境）→ 是不是真问题（悖论式切入：裁判定位不明 / 既有研究集中 Y 而忽视 Z）→ 是不是好问题（面向实际、有利于制度改进）。**信号**：开篇 1000 字内是否明确提出 | 0=无问题仅主题；2=有问题但泛泛；4=三问全过、悖论式切入 | 开篇 1000 字（问题意识习惯在引言亮出，位置本身反映结构意识） | 1.0 |
| S02 | 问题-篇幅匹配 | **原则**：课后作业级问题写 3 万字 = 灌水；博士论文级问题压 1 万字 = 必空泛。**信号**：结合篇幅档位判断；纯实务问题须有充分实践经验内容支撑，否则不适合成文 | 0=体量篇幅严重错配；2=基本匹配；4=篇幅经济且讲透 | 摘要 + 章节大纲（大纲即问题的展开地图） | 1.0 |
| S03 | 子问题分解覆盖 | **原则**：分拆的子问题应无遗漏、无重复、能涵盖问题应论述的每个方面。**信号**：计数标准 = 引言中明确提出的研究问题数量（不含文献综述和结论中的总结性提问）；≤3 能讲透，4 边缘，5+ 必空泛 | 0=分解混乱/遗漏关键方面；2=覆盖基本完整；4=分解精当、层层递进 | 目录 + 章节标题（标题骨架是分解结构的外显） | 1.0 |
| S04 | 子问题解答明确性 | **原则**：每个子问题须有明确结论，且结论可证伪。教义学型可证伪 = "在 X 条件下应当适用 Y 规则"；实证型可证伪 = "可被数据检验的假设"。**信号**："有待进一步研究/值得探讨"留白 = 失分 | 0=普遍留白；2=多数有结论；4=全部明确且可证伪 | 各章小结 + 结语（结论是论证链条的终点） | 1.0 |

### H1-D2 论证结构

| 编号 | 信号 | 判定依据 | 刻度锚点（0/2/4） | 证据位置 | 权重 |
|---|---|---|---|---|---|
| S05 | 标题统摄力 | **原则**：标题骨架是思维结构的外显——只看标题能否看出总论点与逻辑推进。**信号**：一级标题 ≤4 且必须有总论点统摄；标题准确反映核心问题（不过大 / 不过度修辞） | 0=并列堆砌无统摄；2=有结构但平；4=标题串起来即是论证地图 | 目录、章节标题（标题是归纳能力的直接证据） | 1.0 |
| S06 | 章节承接推进 | **原则**：好论证是推进而非罗列。**信号**："基于 X 论证 / 承接上节 Y 论点"类承接语；并列罗列 = 缺总论点 | 0=纯并列；2=有承接但弱；4=环环相扣 | 章节首段、过渡段（承接发生在衔接处） | 1.0 |
| S07 | 逻辑链完整性 | **原则**：循环论证（A 因 B、B 因 A）与无依据跳跃（结论前无推理直接断言）是论证死刑。**信号**：逐章推理段扫描 | 0=存在循环/跳跃；2=基本严密；4=严密且有论证层次感 | 逐章论证段 | 1.0 |
| S08 | 内部一致性 | **原则**：论点、术语、立场前后一致是底线。**信号**：同一概念多次不同定义 / 前后矛盾 = 失分 | 0=存在矛盾；2=一致；4=一致且呼应 | 全文对照 | 1.0 |
| S09 | 取舍意识 | **原则**：敢于取舍 = 作者知道什么重要。评分逻辑写死：主动声明"本文不展开 X 因为 Y" = 有取舍；每个子问题都蜻蜓点水 = 不取舍。**信号**：结语/摘要末段的取舍声明 | 0=面面俱到；2=有侧重；4=明确声明取舍且理由成立 | 结语 / 摘要末段（取舍声明习惯放收尾处） | 0.5 |
| S10 | 回应反驳 | **原则**：主动回应反对意见是论证自信的表现。**信号**："有学者认为 X，但本文认为 Y 因为 Z"；回避反对意见 = 失分 | 0=回避；2=有提及；4=正面回应且有说服力 | 核心论点附近（反驳集中在争议点） | 0.5 |

### H1-D3 结论质量

| 编号 | 信号 | 判定依据 | 刻度锚点（0/2/4） | 证据位置 | 权重 |
|---|---|---|---|---|---|
| S11 | 结论具体性与立场 | **原则**：结语应给出 3–5 条具体可操作结论（立法建议 / 司法解释建议 / 监管办法修订 / 实务指南），且敢于亮明立场。**信号**："应当完善 X 制度"口号 = 失分；"A 有 X 优点 Y 不足，B 有 U 优点 V 不足"骑墙 = 失分 | 0=空泛口号/骑墙；2=有结论但泛；4=具体到条文款项且立场鲜明 | 结语段 | 1.0 |

## 六、H2 文字材料驾驭力（S12–S27）

### H2-D1 文字表达

| 编号 | 信号 | 判定依据 | 刻度锚点（0/2/4） | 证据位置 | 权重 |
|---|---|---|---|---|---|
| S12 | 文字晓畅度 | **原则**：文字晓畅明白，既不故弄玄虚也不词不达意；诘屈聱牙 = 没搞懂概念。**信号**：明显病句/标点错误由评审标注具体位置（不设数量阈值） | 0=多处标注；2=偶发；4=全文晓畅 | 全文，重点抽查 3 段（抽查即可见功底） | 1.0 |
| S13 | 文风控制 | **原则**：连接词堆砌是思维懒惰的外显。**信号**："首先/其次/再次/最后"≥3 层级连用；错别字 | 0=≥3 层连用；2=偶有；4=无 | 全文 + 标点统计 | 0.5 |

### H2-D2 概念与术语

| 编号 | 信号 | 判定依据 | 刻度锚点（0/2/4） | 证据位置 | 权重 |
|---|---|---|---|---|---|
| S14 | 概念界定 | **原则**：定义 = 内涵 + 外延 + 与近义概念的区别。**信号**：核心概念首次出现处是否三者齐备 | 0=无定义；2=有定义不全；4=齐备且有适用范围 | 核心概念首现段 | 1.0 |
| S15 | 术语精确性 | **原则**：针对的是内涵相近但不同的术语误用（如企业/法人/公司，某些时候可混用但内在含义不同）；翻译措辞不同但同义的不算错。**信号**：同一概念随意更换术语 / 近似术语错位使用 | 0=多处误用；2=基本一致；4=精确且统一 | 全文术语对照 | 0.5 |
| S16 | 中外概念对应 | **原则**：域外概念无中国法对应 = 移植无落点。**信号**：首次出现域外概念处是否说明对应关系 | 0=无对应；2=有提及；4=对应关系清晰 | 域外概念首现段 | 0.5 |

### H2-D3 材料与方法运用

| 编号 | 信号 | 判定依据 | 刻度锚点（0/2/4） | 证据位置 | 权重 |
|---|---|---|---|---|---|
| S17 | 论据覆盖 | **原则**：核心论点须有论据，不是观点罗列。论据类型：法条 / 判例 / 实证数据 / 比较法 / 学者观点。**信号**：逐章论点-论据配对 | 0=大量无支撑；2=主要论点有支撑；4=类型丰富且匹配 | 逐章论点段 | 1.0 |
| S18 | 证据-论点匹配 | **原则**：张冠李戴（学者 A 的观点被用来支撑其实不支持的 B 立场）比无引用更恶劣。**信号**：脚注与论点对应抽查 | 0=发现错配；2=基本匹配；4=全部精确 | 脚注-论点对应 | 1.0 |
| S19 | 方法有效性 | **原则**：新方法/跨学科的价值不在"用了"，在"用对了"。三步判定：① 能否把引用的方法解释清楚 ② 能否说明为什么用这个方法 ③ 能否给出合理规范的证明过程与对应结果。纯展示方法 / 浅尝辄止 / 驴唇不对马嘴 = 0 分。注：法教义学是否穷尽不宜武断，不以"用了教义学"扣分 | 0=三步全缺；2=解释清楚但运用浅；4=三步全过且与研究问题适配 | 方法论段 + 工具使用处 | 1.0 |
| S20 | 实证透明度 | **原则**：缺披露 = 缺乏透明度的伪实证。**信号**：样本规模 N、时间区间、筛选标准、可复现检索式（数据库含裁判文书网 / 巨潮 / CSMAR / WIND / 北大法宝 / 威科先行 / Westlaw / HeinOnline / 国家法律法规数据库等） | 0=无披露；2=披露不全；4=全披露且可复现 | 实证方法段 | 1.0 |
| S21 | 数据图表 | **原则**：可视化是材料驾驭的一部分。**信号**：至少 1 张"表 1—X"或"图 1—X"（统计表 / 逻辑框架图 / 类型化矩阵） | 0=无；2=有但粗糙；4=图表增强论证 | 全文扫描"表 X""图 X" | 0.5 |
| S22 | 比较法质量 | **原则**：比较的价值在于"相同情况下的不同"——须说明两法域的相同点与不同点，通过对比看出价值及意义。**信号**：≥3 法域 + 异同说明 + 服务于本土制度建构；只介绍不落地 = 低档 | 0=只介绍；2=有对比未落地；4=对比精当且落地本土 | 比较法段 | 0.5 |
| S23 | 类型化分析 | **原则**：类型化是法学思维的基本功。**信号**：核心问题是否做了二分/三分/四分分层（仅"X 包括 Y 与 Z"过粗） | 0=无；2=有但粗；4=分层精当 | 全文扫描"分为""类型" | 0.5 |

## 七、H3 问题价值与贡献力（S28–S41）

### H3-D1 栏目与选题

| 编号 | 信号 | 判定依据 | 刻度锚点（0/2/4） | 证据位置 | 权重 |
|---|---|---|---|---|---|
| S28 | 栏目契合（含量三档） | **原则**：看"资本市场含量"——文章主轴问题是否必须由资本市场法治回答。含量分档：核心落在资本市场（证券法 / 公司治理 / 监管执法 / 金融刑民交叉，含稳定币、比特币等前沿证券型产品）→ 4 分；交叉型（行刑衔接、ESG 信披、银行保险监管涉资本市场部分、担保保全与资本市场联动、经营者集中涉资本市场）→ 2–3 分；纯刑法（无财产犯罪关联）/ 纯宪法 / 纯行政法 / 纯社会法 / 纯程序法 → 0 分。泛金融话题（银行系统监管）默认交叉档，除非文章自己落到证券市场影响 | 0=纯外围学科；2=交叉但含量低；4=主轴即资本市场 | 标题 + 摘要 + 关键词 + 首段/第一个大标题前部分 + 结尾最后一个大标题（开头亮问题、结尾见落点）。案例评述型无摘要关键词 → 走结构标签特例 | 1.0 |
| S29 | 时效性（五星锚点） | **原则**：以投稿/成文时间为基准算"近 3 年"（解决历史稿件回测的锚点过期问题）。**信号分级**：★★★★★ = 修订草案/征求意见稿/首例案件/新司法解释（成文前 1 年内）；★★★★ = 近 1 年重大案件或监管新规；★★★ = 近 3 年文献与制度动态均有覆盖；★★ = 仅部分新文献；★ = 文献与制度均陈旧 | 0=★；2=★★★；4=★★★★★ | 参考文献年份分布 + "修订草案""首例"等关键词 | 1.0 |
| S30 | 本土回应 | **原则**：回应本土法治现实需求是本表所服务刊物的用稿基本立场；本土问题不限于列举的几起案件。**信号**：是否锚定本土重大事件/本土制度困境（康美、瑞幸、海航、恒大、代表人诉讼首案等仅为示例）；纯比较法无本土落地 = 低档 | 0=无本土落点；2=有提及不深入；4=深度回应本土现实 | 全文检索"中国/我国/本土" + 重大事件关键词 | 1.0 |

### H3-D2 创新性

创新性判断必须基于既有研究摸底，否则创新分只是"自报分"。

| 编号 | 信号 | 判定依据 | 刻度锚点（0/2/4） | 证据位置 | 权重 |
|---|---|---|---|---|---|
| S31 | 新视角 / 新概念 | **原则**：通行定义——以新的分析框架切入既有问题，或提出可命名的原创概念。**信号**：如"二元因果结构""三要素联动"式可命名框架（例子仅作示意，不作判定依据）；"从 X 角度"不新。与 S41 分工：本条问"有没有新视角"，S41 问"是否超越一时一地" | 0=无；2=视角有新意但未成型；4=可命名的原创框架 | 摘要核心论点 + 全文 | 1.0 |
| S32 | 新材料 | **原则**：第一手数据 / 新公开案例 / 立法草案内部资料 = 增量贡献。**信号**：如"312 个样本实证"式自有材料 | 0=无新材料；2=有补充材料；4=独家/一手材料支撑核心结论 | 数据来源段 + 附录 | 1.0 |
| S33 | 新结论 | **原则**：在新视角/新材料/有效方法支撑下得出针对性具体结论，避免重复主流观点。**信号**：结语核心论点 vs 既有研究基线对比 | 0=重复主流；2=有推进；4=实质性新结论 | 结语核心论点 | 1.0 |
| S34 | 面向实践的创新 | **原则**：好稿常因"非宏观创新"被压分——具体可操作的制度方案同样算创新。**信号**：制度构建 / 程序改造 / 规则重构三方向 | 0=无；2=有方向不具体；4=方案具体可操作 | 建议段 / 结语 | 1.0 |
| S35 | 本土针对性（四问细化） | **原则**：移植须过四关。**信号**：① 是否分析中国具体问题及背景 ② 是否说明境外制度的背景与运行情况 ③ 是否在比较中外不同后针对性说明 ④ 是否分析移植前景、优劣利弊 | 0=四问全缺；2=两问；4=四问全答 | 比较法段 + 结语 | 1.0 |
| S36 | 批判-建设性 | **原则**：任何制度都有问题，单纯挑毛病无价值（甚至很多是博弈的结果）；要的是针对实际情况、有利于实践的方式方法。**信号**：批判是否实际、全面、客观理性，且最终落到建设性方案；单纯讲问题 = 低档 | 0=只破不立/胡扯式批判；2=有批判有方案但浅；4=批判精准且建设方案落地 | 全文 + 注释 | 1.0 |

## 附：结构标签定位法

部分信号需要先在文中定位对应段落再判断。常用结构标签：

| 标签 | 对应段落 |
|---|---|
| 摘要 / 关键词 | 首页摘要块 |
| 引言问题段 | 开篇 1000 字 |
| 大纲 / 目录 | 一级、二级标题序列 |
| 文献综述章 | 独立成章或引言后的综述部分 |
| 方法论段 | 交代研究方法与数据来源的段落 |
| 比较法段 | 涉外制度介绍与对比部分 |
| 建议段 / 结语 | 最后一个一级标题至文末 |

案例评述型等特殊体裁缺少标准结构时，按"论述最集中处"就近定位，并在评语中注明。
