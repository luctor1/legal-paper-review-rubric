# legal-paper-review-rubric
面向中文法学论文的信号审稿评分表：为编辑初审、审稿人打分与 LLM 自动评审提供可执行的判定标准。

初步想法是分成三层，第一层是看信息密度，通篇无废话并且可以高效表达内心意思，也就是文字驾驭能力。第二层是逻辑结构，也就是文章整体脉络是否从问题剖析到观点对策呈现出合理有效的逻辑结构。第三层是观点价值，也就是文章提出的一些想法、对策是否解决实际问题、有创新性。

因为平时看论文第一眼通读的时候，看到文字驾驭能力差的，基本上就会倾向于退稿，所以把这个放到第一层。原因在于，一个好的作者一定是经常磨练自己表达的，所以基本功决定了这个文章的上下限。至于剩下的逻辑结构、观点则需要仔细揣摩一下，所以放到第二三层。不过对于机器学习，则不一定是这个顺序，这是一个初步的想法。

初步测试用的主要是《证券法苑》，因为他在交易所官网全公开了pdf版，资源方便获取标准较为统一。正确率大概在60%，之前曾经有过一批样本正确率到了80%，但是不稳定。

这是第二版，第一版是六十多个指标同一重要度发给llm出评分，不好使。所以加了个三层分类，对每个指标再细分一下。

不过还有个问题就是拿不到当今法学前沿领域论文全量，这个不好处理。

另外就是验证最后对策部分写作质量时，需要AI能够假设这个对策不存在的话会怎么样，假设这个对策存在的话会怎么样，似乎AI对于what if的问题还有一定短板。

下一步可能尝试sft微调+rubric，大概就是sft微调模拟学习法学理论的过程，rubric模拟审稿这个专门领域。不过有机会还是想再往AI训练的源头再看一下，感觉llm审稿或者评价文章创新性需要对数据源进行一个专门的设计。

说是做个审稿工具，自己写的七零八碎的。。。
但无论如何，先做个rubric，然后反向解构如何写论文，免除文字搬砖的疲劳并保护颈椎
